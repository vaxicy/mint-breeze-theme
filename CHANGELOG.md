# Changelog

All notable changes to the **Mint Breeze Theme** extension will be documented in this file.

## 1.0.0

- Initial release of **Mint Breeze Theme**.
- **Mint Breeze Light**: fresh mint-white background with a calm pastel palette.
- **Mint Breeze Dark**: deep ocean teal workspace for comfortable night coding.
- Customized workbench UI (activity bar, side bar, title bar, tabs, panels, status bar, inputs, terminal, git decorations, notifications).
- Syntax highlighting tuned for JavaScript, TypeScript, React, JSX, HTML, CSS, JSON, Python and Markdown.
- Semantic highlighting enabled for better TS / JS / Python accuracy.
- Minimal transparent mint-leaf + code-brackets extension icon.
