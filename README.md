# Mint Breeze Theme

[![Visual Studio Marketplace](https://img.shields.io/visual-studio-marketplace/v/lilinhuang.mint-breeze-theme?label=Mint%20Breeze%20Theme&color=8FD8C8&logo=visual-studio-code&logoColor=white)](https://marketplace.visualstudio.com/items?itemName=lilinhuang.mint-breeze-theme)

A fresh, soft and premium mint-green color theme for Visual Studio Code.

Inspired by mint leaves, clean morning air and modern minimal workspaces, Mint Breeze is designed for AI developers, frontend developers, designers and indie hackers who want a calm, focused and aesthetic programming environment.

## Installation

1. Open the **Extensions** sidebar (`Ctrl+Shift+X`).
2. Search for **Mint Breeze Theme**.
3. Click **Install**.
4. Open the Command Palette (`Ctrl+Shift+P`) → `Preferences: Color Theme` → choose **Mint Breeze Light** or **Mint Breeze Dark**.

You can also install directly from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=lilinhuang.mint-breeze-theme).

## Features

- Fresh mint inspired color palette
- Two carefully tuned variants: Light and Dark
- Semantic highlighting tuned for JavaScript, TypeScript, React, JSX, HTML, CSS, JSON, Python and Markdown
- Customized workbench UI: editor, activity bar, side bar, tabs, panels, status bar, terminal, git decorations and notifications
- Premium, minimal interface
- Low-contrast, eye-friendly design for long coding sessions

## Quick Theme Switch

Press `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T` on macOS) to open the color theme picker instantly.
